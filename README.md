# 🕐 World Clock App (Vanilla JS)

World clock application built with vanilla JavaScript as part of my early frontend development journey.

The app uses Moment.js to display current time in selected cities or the user's current location. 

## ✨ Features

- Check the current time for cities available in the select menu
- Detect the user's current location and display the local time

## 🛠️ Tech

- HTML
- CSS
- JavaScript
- Moment.js

## About the project

This was one of my first JavaScript projects, where I practiced working with dates and DOM manipulation.
